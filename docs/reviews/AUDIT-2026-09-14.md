# Release-readiness audit — 2026-09-14

Baseline: `9a67e0a00159be9e15b6f9408ab5e1148b9df440`. Scope: source, interface,
packaging, documentation and automated checks. This is not a penetration-test or
hardware-compatibility certification.

| Finding | Change |
| --- | --- |
| WebTransport bound IPv6-only; the real IPv4 dial tests timed out. | Bind dual-stack so IPv4 LAN and IPv6 clients can connect. Existing transport tests exercise both families. |
| Linked DLLs could be missing on a clean PC before `main()` updated PATH. | Place dependencies beside the EXE; test isolated startup. |
| Build errors and missing DLLs/plugins could produce stale/incomplete packages. | Fail native commands, unresolved imports, absent plugins and missing production assets. |
| Package omitted encoder plugins selected by host policy. | Add AMD, Intel and Media Foundation plugins; keep hardware claims explicit. |
| Admin Host/origin checks were incomplete; WebSockets accepted arbitrary HTTP(S) origins. | Validate loopback authority and browser origins; add real HTTP regression checks. |
| CSP directives could merge; API caching was unspecified. | Fix separators, scope socket sources and set API no-store. |
| Shared TLS files were writable by other local users; DPAPI setup could run as another administrator. | Per-user storage/trust, original-user setup, legacy-CA retirement and migration notes. |
| Key writes could fall back to plaintext; Unicode hex could panic; startup logged the PIN. | Fail DPAPI errors, parse bytes safely and remove PIN logging. |
| Web tests failed discovery; lint failures blocked CI. | Explicit test discovery and baseline lint repairs; strict gates remain. |
| Interface actions had incomplete or silent failure states. | Redesign dashboard/player and test real DOM behavior against host fixtures. |
| Package said proprietary despite GPL; unknown licenses only warned. | Correct app license, fail unknown binaries and preserve distribution notices. |

The PR's latest CI run is the authoritative automated result. Browser tests use
host fixtures. Rust tests cover protocol/policy and local HTTP. The Windows job
builds the installer and checks DLL/plugin loading without a developer PATH.

Real installation, GPU capture, audio, physical input, controllers and networks
still require the [release matrix](../RELEASING.md). Signing and complete matching
source distribution remain release review tasks. This audit certifies no public
release or universal compatibility.
